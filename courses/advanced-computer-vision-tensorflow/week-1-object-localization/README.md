# Week 1 – Predicting Bounding Boxes

Build a model that predicts a bounding box around birds in the Caltech Birds 2010 dataset using transfer learning (MobileNetV2) and a regression head. Performance is measured with Intersection over Union (IoU).

- Notebook: [`C3W1_Assignment.ipynb`](C3W1_Assignment.ipynb)
- Run in Google Colab with a GPU runtime (see the [course README](../README.md)).
