# Week 2 – Zombie Detection

Fine-tune a pretrained RetinaNet (SSD ResNet50 V1 FPN 640×640) with the TensorFlow 2 Object Detection API to detect zombies from only five training images. Only the box/class prediction heads are retrained in a custom eager-mode training loop; the result is rendered as an animated GIF.

- Notebook: [`C3W2_Assignment.ipynb`](C3W2_Assignment.ipynb)
- Run in Google Colab with a GPU runtime (see the [course README](../README.md)).
